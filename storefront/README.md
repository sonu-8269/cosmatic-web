# 🛍️ Storefront (Customer Facing Web App)

- **Framework**: Next.js (App Router) + Tailwind CSS + Lucide Icons + Zustand
- **Features**:
  - Hero video background (H.264 loop, muted, autoplay, poster fallback)
  - Promotional Banner Slider with mobile / desktop responsive optimization
  - Faceted category and skin/hair type filters
  - Interactive product detail page with high-res galleries, reviews, ingredient breakdowns
  - Slide-out Cart Drawer and smooth Checkout with Razorpay & COD support
  - Fast OTP mobile authentication and account management
