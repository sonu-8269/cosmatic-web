# 👑 Super Admin Portal

- **Framework**: React (Vite) + Tailwind CSS + Lucide Icons + React Router + Zustand
- **Target Audience**: Store Owner / Super Administrator
- **Features**:
  - Revenue, orders, and inventory velocity dashboard
  - Full catalog control with confidential buying price fields
  - Role-based Team accounts creation with dynamic action-level checkboxes
  - Comprehensive order fulfillment status pipeline & tracking
  - Coupon management and homepage content curation (banners/videos)
