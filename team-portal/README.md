# 👥 Team Operations Portal

- **Framework**: React (Vite) + Tailwind CSS + React Router + Zustand
- **Target Audience**: Warehouse staff, customer support, catalog editors
- **Features**:
  - Dynamic navigation rendering: only modules assigned by Super Admin are visible
  - Route-level permission guards (403 Forbidden on unauthorized access)
  - Fine-grained action control (e.g., view orders vs update order status)
